# セットアップ手順（Phase 1）

WebApp だけで動く状態にするまでの手順。所要 15〜20 分。

---

## 1. Apps Script プロジェクトを作る

[script.google.com](https://script.google.com) で「新しいプロジェクト」を作成し、名前を `English Studying` にする。

スプレッドシートは **setup() が自動で作る**ので、先に用意する必要はない。
（既存のスプレッドシートに紐づけたい場合は、そのシートの「拡張機能 → Apps Script」から作ってもよい。その場合はそのシートが使われる。）

## 2. マニフェストを編集できるようにする

プロジェクト設定（左メニューの ⚙）で
**「`appsscript.json` マニフェスト ファイルをエディタで表示する」をオン**にする。

## 3. ファイルを配置する

### clasp を使う場合（推奨）

```bash
npx @google/clasp@3 login

cp clasp.json.example gas/.clasp.json
# gas/.clasp.json の scriptId に、プロジェクト設定に表示されている
# 「スクリプト ID」を貼り付ける

cd gas && npx @google/clasp@3 push
```

> `npm install -g @google/clasp@3` でグローバルに入れてもよいが、その場合は
> グローバルの bin（`$(npm prefix -g)/bin`）が PATH に入っている必要がある。
> 入っていないと `clasp: command not found` になる。

### 手でコピーする場合

エディタで以下のファイルを作り、`gas/` 配下の同名ファイルの中身を貼り付ける。

| エディタ上のファイル名 | リポジトリ上のファイル |
|---|---|
| `appsscript.json` | `gas/appsscript.json` |
| `Constants.gs` | `gas/Constants.gs` |
| `Utils.gs` | `gas/Utils.gs` |
| `Srs.gs` | `gas/Srs.gs` |
| `Repository.gs` | `gas/Repository.gs` |
| `Api.gs` | `gas/Api.gs` |
| `Setup.gs` | `gas/Setup.gs` |
| `Code.gs` | `gas/Code.gs` |
| `ui/index.html` | `gas/ui/index.html` |
| `ui/style.html` | `gas/ui/style.html` |
| `ui/app.html` | `gas/ui/app.html` |

HTML は「ファイル → 新規 → HTML ファイル」で作り、**名前に `ui/index` のようにスラッシュを含めて**指定する。

## 4. `setup()` を実行する

エディタ上部の関数プルダウンで `setup` を選び、「実行」。
初回は権限の承認を求められるので許可する。

実行ログ（表示 → ログ）に次が出る。

```
================ セットアップ情報 ================
スプレッドシート : https://docs.google.com/spreadsheets/d/...
トークン         : 32文字のランダム文字列
...
```

**このトークンを控えておく**（後で `showSetupInfo()` を実行すればいつでも再確認できる）。

作成されるシート:

| シート | 内容 |
|---|---|
| `Items` | 語彙本体 |
| `Reviews` | 復習ログ（追記のみ） |
| `Settings` | 1日の上限などの設定 |

## 5. ウェブアプリとしてデプロイする

「デプロイ → 新しいデプロイ」→ 種類は **ウェブアプリ**。

| 項目 | 設定 |
|---|---|
| 説明 | `v1` |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **自分のみ** |

> Phase 2 で Chrome 拡張をつなぐときは、ここを「全員」に変更する。
> UI 側は公開範囲に関わらずトークンを要求するため、「全員」にしても
> URL を知っているだけでは画面を開けない。

デプロイ後に表示される **ウェブアプリの URL** を控える。

## 6. ブックマークする

```
<ウェブアプリのURL>?t=<トークン>
```

この形の URL をブックマークする。`?t=` がないとアクセスを拒否される。

`showSetupInfo()` を実行すると、この URL がログにそのまま出力される。

### スマホで使う

同じ URL を開き、ブラウザの「ホーム画面に追加」をする。
（GAS は `manifest.json` を配信できないため、厳密な PWA にはならない。Google のログインが切れると再認証が必要。）

---

## 使い方

| 画面 | 内容 |
|---|---|
| **ホーム** | 今日の復習・新規・未整備の件数、連続学習日数、8週間のヒートマップ |
| **復習** | フラッシュカード。タップまたは `Space` でめくり、4段階（もう一度 / 難しい / 普通 / 簡単）で評価。`1`〜`4` キー、`P` で発音 |
| **登録** | 英語表現を入力すると種別（単語 / フレーズ / センテンス）を自動判定。品詞は種別に応じた選択肢から選ぶ。**意味が空でも保存できる** |
| **一覧** | 検索・種別・品詞・状態での絞り込み、並び替え、編集、削除（論理削除） |
| **未整備** | 意味が空のアイテムを1件ずつ埋める。ホームのボタンから起動 |
| **設定** | 1日の新規・復習の上限、1セッションの問題数、読み上げの発音（US / UK） |

意味が未入力のアイテムは復習に出題されない。ホームの「未整備」からまとめて埋める。

## 運用上の注意

- **スプレッドシートを直接編集してもよい**。日付列が Date 型になっても読み取り時に正規化される
- **列の順番は変えない**。`Constants.gs` の `ITEM_COLUMNS` が唯一の正で、列を増やすときは末尾に追加する
- **トークンが漏れたら** `resetToken()` を実行し、ブックマークを更新する
- 復習ログ（`Reviews`）は消さない。将来 FSRS に移行する際の再計算に使う

## 2回目以降の反映を自動化する

`gas/` を変更するたびに手で push するのが面倒なら、GitHub Actions から自動反映できる。
設定手順は [DEPLOY.md](DEPLOY.md)。

## 開発

```bash
npm install
npm test        # 純粋関数の単体テスト + 偽シートによる結合テスト
npm run e2e     # 実 UI を Chromium で動かす E2E（サーバー側は偽シート）
npm run e2e:shots   # 上記 + tools/screenshots/ にスクリーンショット出力
```

`tools/fake-gas.js` が `SpreadsheetApp` などを Node 上で偽装しているため、
GAS にデプロイせずにサーバーロジックと UI の両方を検証できる。
