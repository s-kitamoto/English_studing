# English Studying

Google Apps Script + スプレッドシートで作る、英単語・フレーズ・センテンスの記録＆間隔反復復習アプリ。

- **記録**: Chrome拡張（右クリック / ショートカット）または WebApp から登録
- **蓄積**: Google スプレッドシート（Items / Reviews / Settings）
- **復習**: SM-2 ベースの間隔反復。type に応じてフラッシュカード / 4択 / タイピング / 穴埋め / 並べ替え / リスニングを出し分け

単語1語に限らず、フレーズ・イディオム・センテンスを同じ器で扱う。
